# QLU Creative Studio

Interactive QLU learning and creative-assignment workspace from VibeX HQ.

**Prototype only.** QLU, Q, the wallet activity, balances, mining, and transactions shown here are educational simulations with no real funds or network activity.

## Data and privacy
- This website is public; its code is visible to anyone.
- Assignment drafts are saved locally in the browser, **not synced to VibeX HQ**.
- Export and securely retain your assignment JSON backup. Founder Review requires importing a shared file.
- Do not paste passwords, wallet recovery phrases, real financial information, or confidential company data into the app.
- Browser storage can be deleted; keep backups of work.

## Deployment
Serve the bundled `index.html` as a static website, for example with GitHub Pages. No build step required.
